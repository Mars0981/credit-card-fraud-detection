# Experiment Results

The metrics previously recorded in this file were produced by a different experiment configuration and are not treated as reproducible results for the current script. Run `python src/fraud_experiments.py` with the dataset to generate a fresh report, CSV metrics, run metadata, and plots. The current implementation uses a stratified 80/20 holdout, seed 42, probability threshold 0.50, and training-only resampling. No cross-validation metrics are claimed.
